If you've always wanted to have a personal website of your own but felt that buying a server, configuring a domain, and learning front-end development would be too much trouble, GitHub Pages + Hexo is a great option for getting started.

The entire process requires neither a server nor any need to write HTML, CSS, or JavaScript yourself. All you need is a GitHub account and a computer, and you can quickly build a personal website that is accessible at https://username.github.io.

This article uses a Windows environment as an example and walks you through the entire process step by step, from creating a GitHub account to setting up a Hexo blog, configuring SSH, and deploying your website.

16. Why Recommend GitHub Pages + Hexo

If you simply want a personal website, blog, or portfolio, this approach has several obvious advantages.

1) Free

GitHub Pages itself can host static websites for free.

You don't need to purchase VPS, Cloud Server, or Web Hosting.

2) No Need to Build the Entire Website Yourself

Hexo automatically converts Markdown into HTML.

You only need to focus on writing your Markdown file, and Hexo will automatically complete the process of Markdown → HTML/CSS/JS → Your Website

3) Fully Customizable

Hexo is essentially a static site generator.

You can change the theme and modify:

  • HTML
  • CSS
  • JavaScript
  • Page structure
  • Website Logo
  • Navigation Bar
  • Footer
  • SEO
  • Google Analytics

So, it's suitable both for people who are just starting to build a blog and for those who want to gradually learn website development.

4) GitHub: Version Control System

Every time you modify your website, you can use Git to save a version.

If something goes wrong after a change, you can also roll back to an earlier version.

This is also one of the advantages of static websites over traditional CMS platforms.

16. 为什么我推荐 GitHub Pages + Hexo

如果你只是想拥有一个简单的个人网站、博客或者作品集，这套方案有几个非常明显的优势。

1) 免费

GitHub Pages 本身可以免费托管静态网站。

不需要购买VPS、云服务器、Web Hosting。

2) 不需要自己写完整的网站

Hexo 会自动将 Markdown 转换成 HTML。

你只需要专注于写 Markdown 文件，而 Hexo 就会自动完成 Markdown → HTML/CSS/JS → Your Website 这个转换过程。

3) 自定义

Hexo 本质上是一个静态网站生成器。

你可以更换主题，也可以自己修改：

  • HTML
  • CSS
  • JavaScript
  • 页面结构
  • 网站 Logo
  • 导航栏
  • Footer
  • SEO
  • Google Analytics

因此它既适合刚开始搭建博客的人，也适合之后慢慢学习网站开发。

4) GitHub 本身就是版本控制系统

每次修改网站，都可以通过 Git 保存版本。

如果某次修改出现问题，也可以回退到之前的版本。

这也是静态网站相比传统 CMS 的一个优势。
