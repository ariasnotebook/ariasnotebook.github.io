How to Build a Personal Website in 10 Minutes 如何在10分钟内搭建属于你的个人网站

2026.08.13

TBC

如果你一直想拥有一个属于自己的个人网站，却觉得购买服务器、配置域名、学习前端开发太麻烦，那么 GitHub Pages + Hexo 是一个非常适合入门的方案。

整个过程不需要购买服务器，也不需要自己写 HTML、CSS 和 JavaScript。只要准备好一个 GitHub 账号和电脑，就可以快速搭建一个可以通过 https://username.github.io 访问的个人网站。

本文以 Windows 环境为例，从 GitHub 账号创建开始，一步一步完成 Hexo 博客的搭建、SSH 配置以及网站部署。

最终效果：

https://username.github.io

这就是你的个人网站。

一、准备工作

在开始之前，你需要准备：

  • 一个 GitHub 账号
  • 一台 Windows 电脑
  • Git
  • Node.js
  • Hexo
  • 一个用于 GitHub 的邮箱地址

如果你还没有 GitHub 账号，可以先注册一个。

1. 创建 GitHub 账号

首先进入 GitHub (github.com)，注册一个账号。

注册时建议使用一个长期使用的邮箱，例如：

myblog@outlook.com

注册完成之后，你会获得一个 GitHub 用户名：

myblog

这个用户名非常重要，因为后面我们的网站地址、GitHub Repository 名称以及 SSH 配置都会使用它。

若以myblog为例，那么最终个人网站的默认地址就是：

https://myblog.github.io

所以，邮箱用户名决定了你的博客地址。

在创建GitHub帐号之前，请先从注册一个满意的邮箱开始吧 (●'◡'●)

2. 创建 GitHub Repository

登录 GitHub 后，创建一个新的 Repository。

Repository 的名称必须严格按照下面的格式 (以myblog为例)：

myblog.github.io

创建完成之后，你会得到一个类似这样的仓库：

https://github.com/myblog/myblog.github.io

这个 Repository 将用于存放最终部署到 GitHub Pages 的网站内容。

3. 安装 Git、Node.js 和 Hexo

接下来需要在电脑上安装三个工具：

Git

Git 是一个版本控制工具，同时也是我们与 GitHub 进行交互的主要工具。

进入Git官网 (https://git-scm.com/)，点击Install for Windows，按照步骤一步步安装就好。

安装完成之后，在任意文件夹内右键打开 Git Bash，输入：

git --version

如果能够看到类似：

git version 2.x.x

说明 Git 就安装成功了。

Node.js

Hexo 是基于 Node.js 的，因此需要先安装 Node.js。

进入Node.js的官网 (https://nodejs.org/en)，点击Get Node.js，按照步骤完成安装。

安装完成之后，同样在任意文件夹内右键打开 Git Bash，输入：

node -v

以及：

npm -v

如果两个命令都能够正常返回版本号，就说明 Node.js 安装成功。

Hexo

Node.js 安装完成之后，就可以使用 npm 命令安装 Hexo了：

npm install -g hexo-cli

安装完成之后检查：

hexo -v

如果能够看到 Hexo 的版本信息，说明Hexo安装完成。

4. 创建 Hexo 博客

恭喜你！所有准备工作都已经完成，现在就可以开始创建博客了。

首先进入你希望存放博客的目录，例如：

D:\myfolder

然后右键点击Git Bash，输入：

hexo init myblog.github.io

⚠️ 注意，本文后续将仍以myblog为例，实际过程中myblog应当为你自己的邮箱用户名，以及GitHub用户名。

然后进入博客文件夹：

cd myblog.github.io

安装项目依赖：

npm install

现在，一个基础的 Hexo 博客就已经创建完成了。

可以先运行：

hexo server

然后在浏览器打开：

http://localhost:4000

如果能够看到 Hexo 的默认博客页面，说明本地博客已经成功运行。

5. 创建 SSH Key

接下来需要解决一个非常重要的问题：

如何让电脑安全地连接你的 GitHub 账号？

这里使用 SSH Key。

在 Git Bash 中输入：

ssh-keygen -t ed25519 -C "myblog@outlook.com"

其中：

myblog@outlook.com

替换成你 GitHub 使用的邮箱。

执行之后，系统会询问：

Enter file in which to save the key

这时候不要直接使用默认名称。

如果你的电脑用户名是 XXX，可以输入：

/c/Users/XXX/.ssh/id_ed25519_myblog

例如：

/c/Users/myname/.ssh/id_ed25519_myblog

这样做的好处是：

如果你电脑上已经存在其他 GitHub 账号，就可以通过不同的 SSH Key 区分不同账号。

接下来可能会要求你设置 passphrase。

如果只是个人博客，也可以直接按 Enter 跳过。

完成之后，.ssh 文件夹中应该会出现两个文件：

id_ed25519_myblog
id_ed25519_myblog.pub

其中：

id_ed25519_myblog

是私钥。

id_ed25519_myblog.pub

是公钥。

⚠️ 注意：不要把没有 .pub 后缀的私钥上传到 GitHub，也不要公开分享。

6. 配置 SSH Config

如果你只有一个 GitHub 账号，这一步通常比较简单。

但如果你电脑上同时使用多个 GitHub 账号，建议配置 SSH config 文件。

进入：

C:\Users\XXX\.ssh\

如果没有 config 文件，就创建一个名为：

config

的文件。

然后添加：

Host myblog.github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_myblog

其中，myblog应换成你自己的邮箱用户名（在后文里我真的不会再重复了！）

7. 将 SSH Key 添加到 GitHub

进入：

C:\Users\XXX\.ssh\

找到刚才生成的：

id_ed25519_myblog.pub

可以使用下面的命令查看它：

cat ~/.ssh/id_ed25519_myblog.pub

你会看到一长串类似：

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI...... myblog@outlook.com

你需要复制完整内容。

接下来打开 GitHub：

Settings → SSH and GPG keys → New SSH key

填写Title

例如：

My Windows PC

Key type 保持默认的Authentication Key。

然后把刚才复制的公钥粘贴到Key的输入框中。

最后点击 Add SSH key。

大功告成！

8. 测试 SSH 是否配置成功

在 Git Bash 中运行：

ssh -T git@myblog.github.com

如果第一次连接 GitHub，可能会出现：

Are you sure you want to continue connecting (yes/no/[fingerprint])?

输入：

yes

如果配置成功，应该可以看到类似：

Hi myblog! You've successfully authenticated, but GitHub does not provide shell access.

看到这句话，就说明你的电脑已经成功通过 SSH 连接到 GitHub了。

9. 修改 Hexo 的 _config.yml

回到你的 Hexo 博客目录，也就是打开下面这个文件夹：

myblog.github.io

找到一个名叫_config.yml的文件，这是 Hexo 的核心配置文件。

打开该文件，找到

deploy:

然后配置 GitHub 部署信息。输入：

deploy:
  type: git
  repo: git@myblog.github.com:myblog/myblog.github.io.git
  branch: master

随后保存该文件。

10. 安装 Hexo Git 部署插件

在Hexo 博客文件夹下打开Git Bash，然后输入：

npm install hexo-deployer-git --save

这个插件的作用是：

让 Hexo 可以直接把生成好的网站文件部署到 GitHub。

安装完成之后，就可以尝试第一次部署了（终于！）

11. 第一次部署：失败

在Hexo 博客文件夹下打开Git Bash，并运行：

hexo clean && hexo g -d

这里的hexo clean用于清除之前生成的缓存文件。

hexo g 是命令hexo generate的缩写，用于生成网站静态文件。

hexo d 是命令hexo deploy的缩写，用于将网站部署到 GitHub。

所以：

hexo clean && hexo g -d

实际上就是：

清理 → 重新生成 → 部署

不过，如果你第一次按照上面的方式配置 GitHub SSH，不用担心，这一步一定会失败。

12. 修改 .deploy_git 中的 Git Config

运行第一次部署之后，Hexo 会在你的博客文件夹下生成一个名为 .deploy_git的文件夹。

进入：

.deploy_git/.git/

找到一个名为config的文件：

用文本编辑器或其它你喜欢的方式打开它。

在 [core] 等配置的下方，增加：

[user]
    name = myblog
    email = myblog@outlook.com
[branch "master"]
    remote = git@myblog.github.com:myblog/myblog.github.io.git
    merge = refs/heads/master

其中, myblog@outlook.com 替换成你注册Github的邮箱。

13. 再次部署

现在回到 Hexo 博客的根目录，也就是myblog.github.io文件夹下，打开Git Bash，再次运行：

hexo clean && hexo g -d

如果前面的 SSH、GitHub Repository 和 Hexo 配置都正确，你会看到类似：

INFO  Deploy done: git

这意味着：

恭喜，你的个人网站已经成功部署到 GitHub Pages！

14. 打开你的个人网站

现在打开浏览器，输入：

https://myblog.github.io

如果一切正常，你就可以看到刚刚创建的 Hexo 博客。

🎉 至此，一个属于你自己的个人网站就搭建完成了！

15. 以后如何更新网站？

搭建完成之后，日常维护其实非常简单。

如果想创建一篇新的文章：

hexo new "My First Post"

Hexo 会在：

source/_posts/

下面生成一个 Markdown 文件。

例如：

source/_posts/my-first-post.md

然后你可以直接使用 Markdown 编辑文章。

例如：

# My First Post

Hello, this is my personal website.

## About Me

I am a .

文章写完之后，只需要运行：

hexo clean && hexo g -d

Hexo 就会：

Markdown
   ↓
Hexo Generate
   ↓
HTML / CSS / JS
   ↓
GitHub Pages
   ↓
你的个人网站

通常等待几十秒，就可以在网站上看到最新内容。

或者你也可以分开运行：

hexo clean
hexo g
hexo d

如果想要学习如何发布一篇新博文，或者更换更好看的主题，可以查看：如何在你的Hexo博客中发布文章

16. 为什么推荐 GitHub Pages + Hexo？

如果你只是想拥有一个简单的个人网站、博客或者作品集，这套方案有几个非常明显的优势。

① 免费

GitHub Pages 本身可以免费托管静态网站。

不需要购买：

  • VPS
  • 云服务器
  • Web Hosting

② 不需要自己写完整的网站

Hexo 会自动将 Markdown 转换成 HTML。

你只需要专注于：

写 Markdown

而 Hexo 负责：

Markdown
↓
HTML
↓
Static Website

③ 可以完全自定义

Hexo 本质上是一个静态网站生成器。

你可以更换主题，也可以自己修改：

  • HTML
  • CSS
  • JavaScript
  • 页面结构
  • 网站 Logo
  • 导航栏
  • Footer
  • SEO
  • Google Analytics

因此它既适合刚开始搭建博客的人，也适合之后慢慢学习网站开发。

④ GitHub 本身就是版本控制系统

每次修改网站，都可以通过 Git 保存版本。

如果某次修改出现问题，也可以回退到之前的版本。

这也是静态网站相比传统 CMS 的一个优势。

17. 最终流程总结

如果把整个过程压缩成一张流程图，其实就是：

创建 GitHub 账号
        ↓
创建 username.github.io Repository
        ↓
安装 Git + Node.js + Hexo
        ↓
hexo init username.github.io
        ↓
生成 SSH Key
        ↓
配置 ~/.ssh/config
        ↓
将 .pub 公钥添加到 GitHub
        ↓
配置 Hexo _config.yml
        ↓
安装 hexo-deployer-git
        ↓
hexo clean && hexo g -d
        ↓
解决 .deploy_git Git Config
        ↓
再次部署
        ↓
https://username.github.io

整个过程中真正比较容易卡住的地方，其实就是 SSH Key + Git Config。

一旦这部分配置完成，后面的更新其实就非常简单啦。

结语

很多人都曾经想拥有自己的个人网站，却因为做网站是一件很复杂的事情而放弃。

实际上，如果你的需求只是：

拥有一个属于自己的博客、个人主页、作品集或者在线简历。

那么并不需要从服务器、数据库和前端框架开始学习。

GitHub Pages + Hexo + Markdown 就足够让你快速建立自己的第一个网站。

快去试试吧 (^_^)
